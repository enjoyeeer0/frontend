# Интернет-магазин на Vue

Каталог товаров с поиском, фильтром по категориям, сортировкой по цене и корзиной.

## Запуск

```sh
npm i
npm run dev
```

## Структура

- `src/data/products.ts` — массив товаров
- `src/components/ProductCard.vue` — карточка товара
- `src/views/HomeView.vue` — страница магазина: каталог и корзина
- `public/images/` — картинки товаров
